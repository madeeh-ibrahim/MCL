## Why version 2

v1 derived the twelve coupling weights from a fixed public constant, so the map F was the same for every input. Against a fixed 128-bit map a Hellman / distinguished-point precomputation (W₀ chain points, M stored distinguished points) lets an online walk of N steps jump ahead with probability ≈ (1−ε)·N·W₀/2¹²⁸ — ≈ 2⁻¹⁰ at N = 2⁴⁰, W₀ = 2⁸⁰ — against the W₀/(ε·2¹²⁸) ≈ 2⁻⁴⁶ the v1 conjecture stated. `p4_tmto_toy.py` reproduces the gap on a random 32-bit mapping (measured 2.27e-2 vs the v1 term 7.3e-6). v2 derives the weights from **h = SHA-256(x)** through the sidecar's audited `mcl_t4_q30_params_from_key(h, 0)` (label "MCL-T4-Q30-v1", range [2, 2³⁰), p≠q rule, seed-reachable-symmetry re-draw), so every input evaluates its own map F_x; the initial state is unchanged, the output tag is `MCL-VDF128-T4-v2-out`, the per-iteration cost is identical.

## Round 6 (2026-09-05 evening) — VDF128-T4 **version 3**: neutral domain strings + full-rank parity rule; theory section; distinguisher search

**Why version 3.** (a) The version-2 strings ("MCL-VDF128-T4-v2-out", "MCL-T4-Q30-v1", "MCL-VDF128-KAT-1") carried the project name into the double-blind PDF and are searchable to this repository; v3 uses `VDF128-T4-v3-kdf`, `VDF128-T4-v3-out` (16 ASCII + 8 NUL) and the KAT input `VDF128-T4-KAT-01`. (b) The new single-bit **differential probe** (`p4_vdf128v3_distinguisher.cpp`, part A) found on the version-2 battery instance a **probability-one differential**: flipping the top bit of one state word gave the same 128-bit output difference for all 65,536 states through every iteration, because all six weights touching that word were even — a single-word half-turn translation symmetry that the sidecar's seed-reachable test does not cover. Exact criterion: the map has a translation symmetry iff the 12×4 parity matrix of the weights is rank-deficient over GF(2) (rows q·e_i + p·e_j and p·e_i + q·e_j mod 2). `mcl_vdf128_t4_v3.hpp` re-draws until the rank is 4 (`mcl_vdf128v3_parity_rank`); the old derivation is kept as `..._oldrule` for statistics. Map, initialization and table unchanged.
