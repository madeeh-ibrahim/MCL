## معايير القراءة (مسجَّلة مسبقاً)
- **A/B (المخرجات المنشورة):** ✅ إشغال 2-D ≈ التوقع المطبوع، |z| للـχ² < 4، H ≈ التوقع المطبوع ±0.02 بت، الإنتروبيا الشرطية ≈ التوقع المطبوع، AMI ≈ الانحياز فقط، FNN وD2 للسلسلة ≈ البديل المخلوط → «لا بنية منخفضة البعد قابلة للاستغلال في المخرجات المكشوفة». 🔴 FNN للسلسلة ≪ البديل، أو D2 يُشبع تحت البديل، أو AMI فوق الانحياز بوضوح، أو خريطة عودة منحنية/إشغال منخفض = بنية مكشوفة تُفحص فوراً. **القيم المطلقة (مثل D2≈m) ليست معايير** عند هذا n.
- **C §4 (EFA):** ✅ خطأ المسار وخطأ الخطوة الواحدة ≈ 64/128 (σ≈0.09 عند L=4096) لكل δ صغيرة، بلا حوض حول δ=0؛ **متوقَّع ومُعلَن:** انخفاضات بنيوية عند δ=2^k الكبيرة (≈2.8 بت عند k=29، ≈1.2 عند k=28) لأن δ·t2 mod 2^32 يصفر باحتمال 2^−(32−k) — تسريب بتات الوزن العليا من الحالة الخام = بنية الشبكة المعروفة التي تبرّر سياسة «لا تصدير للحالة الخام». 🔴 أي حوض/منحنى رتيب عند δ الصغيرة.
- **A §4 (تيار المفاتيح):** ✅ HD/8 ≈ 4.00 لكل δ≠0 (بما فيها 2^29) — لا EFA ممكن بلا إعادة تزامن.
- **D (الضابط):** قد يبدو «سليماً» في §1–§3 رغم أنه مكسور جبرياً — وهذا الدرس يُكتب في السجل: الاختبارات الإحصائية/الطوبولوجية **لا تكشف** الكسر الجبري؛ الدليل الحقيقي هجوم بنيوي (يتّسق مع Alvarez–Li Rule 10/16 «ضروري غير كافٍ»).
- **§5:** المتوقع مرشّح واحد من 2^24 (احتمال الناجي الزائف ≈ 0.016 بعد خطوة واحدة، ≈0 بعد R=4) → الحالة الخام الكاملة تحت معرفة جزئية **تحدد** الزوج؛ واجهة `commit32` غير قابلة للتقييم بنفس الطريقة (XOR) وتُسجَّل N/A مع الإحالة إلى `08_attack_t4_commit32.py`.
