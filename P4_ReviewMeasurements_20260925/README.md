## Why version 4
Review #16 (2026-09-25, `05_Scientific_Papers/Paper_4_IACR_CiC/Reviews/P4_ReadOnly_Adjudication_20260925g.md` + `h.md`, measurements in `Reviews/P4_Dev_20260925/`) showed that the memory-bounded generic floor of an **unclocked** per-input map is of order min(P,M)·N²/2^s, not N·M/2^s (a walk that touches the honest path follows it and is recognized at the next stored point), so the version-3 conjecture SCIA-128 sat below a generic attack at deployment budgets. Version 4 injects the 64-bit iteration number into every iteration (τ(i) = (lo, lo·A+hi, lo·B+hi·A, lo·C+hi·B) mod 2^32, A = 0x9E3779B1, B = 0x85EBCA77, C = 0xC2B2AE3D, lo = i mod 2^32, hi = i>>32, i from 0 at the first burn-in iteration) before the four Gauss-Seidel word updates; output tag `VDF128-T4-v4-out`; **weight derivation, its KDF label included, initialisation and table are byte-identical to v3** (so every v3 weight-distribution measurement applies verbatim). Ideal-model bound: (q+1)/2^s for any q-query adversary at depth < N (Paper 4 v4, Theorem 1).
