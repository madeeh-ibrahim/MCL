# T4_CycleStructure — cycle structure of the T4-Q30 engine at reduced state width (English summary)

Doc ID MCL-T4-CYCLE-2026-0822-001 · engine `mcl_core.hpp` 8.1.1 + `keyed_q30_PQ/mcl_keyed_q30.hpp`, both unmodified (additional tools only) · Apple M-series · full record in Arabic: `T4_CYCLE_RECORD_20260822.md`, raw logs in this folder.

**What is measured.** The same four-oscillator Q30 map is run with w bits per angle (state 4w bits, w = 8 … 14, i.e. 32–56-bit states), in two reductions: R1 truncates the full 32-bit path, R2 runs the original w-bit path (the engine as it actually computes). For every width, all seeds of 16 keys (4 at w = 13, 14) are iterated to closure with Brent's algorithm (no censoring), and the cycle length λ and the rho length ρ = μ + λ are compared with the random-mapping model (E[λ] = √(πN/8)).

**Result.** R1 follows the random-mapping model (slope ≈ 0.50 per state bit; ρ/E[ρ] 0.92–1.07, λ/E[λ] 0.95–1.44). R2 — the engine itself — also has slope ≈ 0.5 (0.497 ± 0.026 for λ, 0.490 ± 0.010 for ρ) but sits below the model at every width (ρ/E[ρ] 0.37–0.59, λ/E[λ] 0.30–0.80). Extrapolated to the 128-bit Q30 state with the theoretical slope 0.5 and the measured ratio (`fit7_summary.txt`): **λ₁₂₈ ≈ 2^62.3 ± 0.2** and ρ₁₂₈ ≈ 2^63.2 ± 0.1, a factor ≈ 2 below the random-mapping model. The free-slope fits give 2^62.1 / 2^62.4 with ±2.2 / ±0.8-bit prediction error and are not quoted alone. This is an extrapolation from 32–56-bit states, not a measurement at 128 bits; Paper 5 §VIII quotes it as such.

**Also here.** The exact translation-symmetry group of the integer map (`mcl_symmetry_group_exact.cpp`), its reachability from the seed (`mcl_symmetry_check.cpp`, `mcl_cycle_translates_check.cpp`: the three terminal cycles of the binary core (3, 5) are translates of one cycle), its impact (`mcl_symmetry_impact.cpp`), the weak-key parity condition behind the sidecar's re-draw (`mcl_weakkey_parity_check.cpp`, ≈ 2⁻⁹ of keyed weight sets; fixed in sidecar v1.0.6), and the double-precision and VDF128 checks.
